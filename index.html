What it is

Networking that fits how apps are actually built

The goal is to give mobile engineers a secure connection layer they can add in an afternoon, not a project for the IT team.

>_

Simple SDK

One initialise call and one connect call. Sensible defaults, with options when you need them.

</>

Native iOS and React Native

Swift and Objective-C bindings plus a React Native module, so it feels at home in your stack.

⇄

Smooth network handover

Designed to recover gracefully when a device moves between Wi-Fi and cellular.

▤

Per-app routing

Route only your app's traffic, with separate settings for staging and production.

How it would work

From install to working tunnel in minutes

That's the target we're designing towards. Your feedback will shape what ships first.

  1. Create a project

    Get an API key from a simple dashboard and pick your region.

  2. Add the SDK

    Install the package for iOS or React Native and initialise it with your key.

  3. Connect and monitor

    Open a tunnel with one call, then check usage and connection health in the dashboard.

Why different

Aimed at app teams, not IT admins

General-purpose VPN tools solve a different problem. We're focused on the one app developers actually have.

What we're designing for

  • Built for app developers, not network administrators
  • A drop-in SDK with a single initialise and connect flow
  • Native iOS and React Native bindings
  • Smooth reconnects when switching networks

What we're not

  • Not a consumer VPN app
  • Not a desktop client wrapped for mobile
  • Not a compliance certification: any compliance features are planned and will be documented honestly
