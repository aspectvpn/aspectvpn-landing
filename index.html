How it would work

Built for how apps are actually made

The goal is a secure connection layer a mobile engineer can add in an afternoon. This is the design we're aiming for, and your feedback will shape it.

01

Create a project

Get an API key from a simple dashboard and pick a region.

02

Add the SDK

Native iOS and React Native bindings with one initialise call.

03

Connect and monitor

Open a tunnel with one call. Designed to recover smoothly when switching between Wi-Fi and cellular.

What we're designing for

  • Built for app developers, not IT admins
  • Drop-in SDK with a simple connect flow
  • Per-app routing for staging and production

What we're not

  • Not a consumer VPN app
  • Not a desktop client wrapped for mobile
  • Not yet certified. Compliance features are planned and will be documented honestly

FAQ

Questions

Is the product available now?

No. This is an early-stage concept and the SDK isn't publicly available yet. The waitlist helps us decide what to build first.

Will you log my users' traffic?

We haven't finalised a logging policy. Privacy is a core design goal, and we'll publish a clear, specific policy before any public release.

How much will it cost?

Pricing isn't set. We expect a simple per-app or per-team subscription, and waitlist members will hear first.
